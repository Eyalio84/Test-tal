### 5. OAuth Redirect Loop Fix (`ERR_TOO_MANY_REDIRECTS`)
**Root cause:** `pages: { signIn: "/api/auth/signin" }` in `lib/auth.config.ts` told NextAuth to redirect to its own handler on auth failure → infinite loop.

**Fix:** Removed `pages` override and the unused `authorized()` callback (no middleware exists, admin protection is at layout level).

`lib/auth.config.ts` now just exports providers:
```ts
export const authConfig: NextAuthConfig = {
  providers: [Google({ ... })],
}
```
