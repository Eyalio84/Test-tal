## Key Decisions

1. **Benchmark before building.** Original plan had Haiku benchmark in Task 5. User correctly identified this encodes unverified assumptions as facts. Plan was restructured: benchmark is Phase 1, everything else waits for results.

2. **CDN migration is permanent.** Images live on R2. The static theme TS files keep Unsplash URLs as display fallbacks (non-breaking), but `resolveTheme()` always prefers the DB `ThemeImage` record which points to R2.

3. **Model-hint guide is empirical.** The generalization-guide.md documents exactly which capabilities were tested and what the results were. Claims are cited to specific benchmark questions.

4. **hybrid-execute replaces two options.** Previous c_plan workflow asked "Subagent-Driven or Parallel Session?" hybrid-execute generates the paste prompt automatically — no decision required from the user.

5. **Pre/Post launch tooling in CLAUDE.md.** Rate limiting (Upstash), analytics (PostHog), background jobs (Trigger.dev) are documented as "add when you have real users" — not installed prematurely.
